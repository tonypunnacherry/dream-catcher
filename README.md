# Dream Catcher

AI-based application that analyzes your dreams and automatically builds you a dream journal. Journal will contain your own dream, notes, and AI-generated analysis.

## Credits: 

Utilized [GenStack](https://genstack.ssennett.net/) to convert Party Rock application into a full stack Svelte application.
A lot of the code used is based off the code generated by GenStack, but it was heavily modified for our UI customizations.

AWS Bedrock Gen AI was used for text and image prompts. Prompts were generated and designed by us in AWS PartyRock.

## Usage:
Currently, the app is not deployed for usage online - but we plan to demo it to judges and anyone interested on our devices. If you'd like to try it, you can copy the project onto your folder, run `npm install` on the latest version of Node.js, then run `npm run dev`. You can see how the UI works, but the generative AI will not work. If you want to try the Generative AI, you can generate your own credentials and add them into `src/routes/api/call-bedrock/handlers.ts`.

We currently do not have any active API keys in use, so you will need to generate your own Bedrock API key.
