# Dream Catcher

## Credits: 

Utilized [GenStack](https://genstack.ssennett.net/) to convert Party Rock application into a full stack Svelte application.
A lot of the code used is based off the code generated by GenStack, but it was heavily modified for our UI customizations.

AWS Bedrock Gen AI was used for text and image prompts. Prompts were generated and designed by us in AWS PartyRock.

## Usage:
Currently, the app is not deployed for usage online - but we plan to demo it to judges and anyone interested on our devices. It is using currently charging us from AWS to use the AI tools, and we do not want to publicize access to this AI which would incur us more costs. If you'd like to try it, you can copy the project onto your folder, run `npm install` on the latest version of Node.js, then run `npm run dev`. You can see how the UI works, but the generative AI will not work. If you want to try the Generative AI, you can generate your own credentials and add them into `src/routes/api/call-bedrock/handlers.ts`.
